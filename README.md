# Yoann Rousselin

CNRS research engineer in **X-ray crystallography** at the ICMUB (Institut de Chimie Moléculaire de l'Université de Bourgogne), Dijon, France.
*Ingénieur de recherche CNRS en cristallographie, ICMUB, Dijon.*

I determine crystal structures for chemistry research teams, and I write small **Python tools** that make everyday crystallographic work easier. Most of them are adaptations of existing software and libraries, which are credited in each project.

## 🧰 Tools for Mercury (CCDC)

| Project | What it does |
|---|---|
| [mercury-ring-puckering](https://github.com/yrousselin/mercury-ring-puckering) | Cremer–Pople puckering parameters and conformation of 5- and 6-membered rings |
| [mercury-cshm-csm-ccm](https://github.com/yrousselin/mercury-cshm-csm-ccm) | Shape, symmetry and chirality of metal coordination spheres (CShM, CSM, CCM) with cosymlib |
| [mercury-raspa3-porosity](https://github.com/yrousselin/mercury-raspa3-porosity) | Experimental vs simulated porosity (RASPA3 GCMC, BET, pore geometry) |

## 🔬 Plugins for GSAS-II

| Project | What it does |
|---|---|
| [gsasii-autoindex](https://github.com/yrousselin/gsasii-autoindex) | Auto-indexing of powder patterns with several methods (Conograph, dichotomy, trial-and-error, GSAS-II) |
| [gsasii-cellsearch](https://github.com/yrousselin/gsasii-cellsearch) | Search COD, CSD and local CIF folders by unit cell |
| [gsasii-phasematch](https://github.com/yrousselin/gsasii-phasematch) | Interactive phase identification (search-match) in powder patterns |

## 💎 Tools for Bruker APEX6

| Project | What it does |
|---|---|
| [apex6-report](https://github.com/yrousselin/apex6-report) | Experimental report from APEX6 / SAINT files (cell, data collection, statistics, data-quality summary), as a macOS / Windows app or a Python script |

Each project has an English (README) and a French (LISEZMOI) guide, with installation instructions for macOS and Windows.
